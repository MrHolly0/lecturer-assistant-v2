# ADR-002: Bootstrap первого администратора

Контекст: регистрация по ТЗ идёт через приглашения, но в пустой установке ещё нет администратора, который может создать первое приглашение.

Решение: добавить `POST /api/v1/auth/bootstrap-admin`, доступный только пока `iam.persons` пустая.

Почему: это закрывает on-prem установку без секретов в репозитории и без ручного SQL.

После первого пользователя endpoint всегда возвращает `409`.

Обычные админы, лекторы и студенты дальше создаются только через invitation-flow.

JWT/refresh и роли применяются к bootstrap-admin так же, как к обычной регистрации.

Решение локально для фазы 1 и не меняет технологический стек §3.1.

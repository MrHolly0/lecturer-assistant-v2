# ADR-003: Golden-файлы контента фазы 2

Контекст: ТЗ требует golden-набор реальных презентаций из v1, включая PPTX.

Факт: в v1 найдены только PDF-файлы; PPT, PPTX и ODP в дереве проекта отсутствуют.

Решение: добавить в CI реальный PDF из v1 как golden-файл фазы 2.

Решение: конвертер поддерживает PDF напрямую и Office-форматы через LibreOffice headless.

Почему: нельзя синтетически создать «проблемный v1 PPTX» и выдать его за артефакт v1.

Почему: PDF-golden всё равно проверяет upload/import/versioning/cache path на реальном файле.

Следствие: когда появится настоящий v1 PPTX, его нужно положить в `core/src/test/resources/golden/content/`.

Следствие: DoD по PPTX считается неполным до появления реального PPTX-артефакта.

Статус: принято для фазы 2.

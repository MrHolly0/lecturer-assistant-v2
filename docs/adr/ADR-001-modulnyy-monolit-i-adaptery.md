# ADR-001: Модульный монолит и адаптеры каналов

Дата: 2026-06-11.

Контекст: v1 распался на сервисы не по доменным границам, а Telegram-бот оказался внутри домена.

Решение: строим `core` как модульный монолит на Java 21 + Spring Boot 3.x, с пакетами `iam|org|content|live|qa|feedback|interaction|channel|analytics|shared`.

Решение: Telegram, VK и будущие каналы работают отдельными процессами-адаптерами через Channel SPI.

Почему: команда маленькая, один Postgres даёт транзакции и JOIN, а ArchUnit сохраняет дисциплину модулей.

Почему: адаптеры имеют другой жизненный цикл и внешние лимиты, поэтому не должны тянуть SDK в ядро.

Следствие: `core` владеет доменом и БД; адаптеры stateless, кроме транспортных кэшей.

Следствие: новый канал добавляется без изменения доменной логики.

Статус: принято техническим заданием `docs/ARCHITECTURE_V2.md`.

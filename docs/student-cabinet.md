# Кабинет студента и переключение занятий

Обычный вход студента показывает текущие занятия его групп и историю посещений.
Незавершённое старое занятие не перехватывает навигацию. Можно подключиться по коду,
покинуть занятие, перейти к другому и вернуться с сохранением записи участника.
Сопоставление групп между курсами использует настроенную структуру учреждения.
Запрет доступа к курсу исключает его занятия из списка доступных.

Выход не завершает занятие преподавателя. Поздние команды и квитанции не возобновляют
участие. Явный возврат заменяет старый токен участия новым. Для гостя возможность
вернуться зависит от сохранённого локального токена; история аккаунта не берётся
по совпадению имени. При входе в аккаунт текущее гостевое участие может быть перенесено
по прежнему подтверждаемому токеном сценарию.

Кабинет работает с существующим MAX и браузером. Вход через Telegram/VK находится
в отдельной экспериментальной ветке и не включён в эту версию.

## Итоги проверки и ограничения

Локально: полный прогон 421 серверного теста, 142 веб-теста, 32 теста сервисов с PostgreSQL на Node 24,
32 теста MAX на Node 24 и 55 тестов развёртывания/обновлений/конвертера. Все прошли.
Веб также прошёл генерацию API, lint, форматирование и сборку; Maven verify включает
проверки стиля. После полного прогона добавлена регрессия отката бизнес-транзакции:
созданный файл удаляется вместе с откатившимся резервом, включая загрузки вложений.
Она и связанные проверки хранения/импорта прошли отдельным прогоном.
Дополнительные контейнерные проверки перечислены в таблице.
Сводка без секретов: [validation/security-performance-remediation.json](validation/security-performance-remediation.json).

Это не сертификат отсутствия уязвимостей и не подтверждение 10 000 видеозрителей.
На текущем Mac недостаточно выделенной Docker памяти для безопасного запуска полного
пакета с новым бюджетом рядом с рабочими сервисами; проверялись отдельные компоненты.
Для выпуска учреждению остаются смешанная нагрузка/soak на целевой Linux-ВМ, измерение
сети и видео, полное восстановление новой зашифрованной копии и подключение Alertmanager.
Старый plain backup/restore проверялся ранее; новый состав копии проверен по частям,
но полный новый encrypted recovery всей установки здесь не заявляется проверенным.

Размер PVC local-path не является жёсткой квотой файловой системы. Для гарантированной
изоляции диска нужны отдельная файловая система/квоты хоста. Одна ВМ остаётся единой
точкой отказа. Раздельные роли RabbitMQ введены в appliance; внешний брокер native HA
должен получать минимальные права по процедуре своего администратора.

В HTTP включены nosniff/no-referrer и CSP **report-only**, сохраняющий MAX. Политика ещё
не блокирует нарушения CSP. Образы nginx и Caddy обновлены с проверенными digest;
полный анализ их OS-пакетов выполняет release workflow, а не npm audit.

## Переход существующей установки

Не выпускать исправление как image-only обновление базы 53. Нужны согласованная новая
топология (scratch, MAX inbox, ключ конвертера, роли брокера, мониторинг), внешняя копия
и обслуживание. Сборщик каталога требует минимальную схему 56: это предохранитель от
ошибочной публикации совместимости, а не автоматическая миграция инфраструктуры.
После перехода следующие совместимые обновления снова доступны из интерфейса.
Подробности: [пакет одной ВМ](../deploy/appliance/README.md), [реакция на предупреждения](operations-alerts.md).

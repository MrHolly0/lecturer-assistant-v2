# Формат учебных групп учреждения

Администратор настраивает «Ещё → Формат групп»: части названия, их порядок,
разделители и допустимые варианты. Можно использовать справочник, год или номер.
Пример: уровень `б`, направление `ИСТ`, год поступления `23`, номер `4` дают
`бИСТ-234`. Уровень по умолчанию разрешает пропустить `б`, если так принято в вузе.
Магистратура и бакалавриат сохраняют разные структурные ключи.

Преподаватель сначала вводит название одной строкой. Регистр, пробелы и тире
нормализуются. Валидная группа принимается сразу. При ошибке или неоднозначности
появляется короткая пошаговая форма; распознанные поля заполнены. Это действует
и в создании группы курса, и при подключении групп к занятию. API повторяет
проверку независимо от браузера.

Формат выключен по умолчанию. Администратор может взять пример за основу или
собрать свой из максимум восьми частей. Сервер не исполняет произвольные регулярные
выражения или скрипты. Одновременные изменения настроек защищены номером ревизии.

Смена правил не переписывает старые названия, составы и посещения. Кнопка проверки
существующих групп связывает только распознанные структуры, до 1000 записей за раз;
неоднозначные названия оставляет для проверки. Автоматического слияния строк нет.
Смысловые идентификаторы частей сохраняются при перестановке; изменение смысла
поля требует пересмотра правил и явной проверки существующих групп.

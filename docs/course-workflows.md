# Работа с курсом

## Интерфейс

- Подложка линии вкладок заканчивается под последней вкладкой. На узком экране вкладки прокручиваются внутри своей области.
- «Лекции» и «Презентации» разделены отступом, без дополнительной линии между разделами.
- Создание лекции и загрузка презентации открываются в диалогах. Заголовок страницы, поиск и списки остаются на месте. Закрытие диалога загрузки не отменяет начатый импорт; его состояние остаётся на странице.
- Черновик лекции сохраняется при закрытии и ошибке. Завершение импорта не подменяет уже выбранную презентацию или заполненное название.
- На широком экране запуск занятия стоит в одной строке с выбором лекции. На телефоне кнопка занимает отдельную строку на всю ширину.
- «Доступ: …» в списке сотрудников — кнопка с иконкой щита, открывающая диалог, без стрелки выпадающего списка.

## Существующий участник

«Люди и доступ → Добавить участника → По email»: ввести полный адрес, найти аккаунт, проверить имя, выбрать роль в курсе и необязательную учебную группу для студента, нажать «Добавить в курс». Состав обновляется сразу. Вторая вкладка создаёт приглашение; результат сохраняется при переключении вкладок открытого диалога.

Поиск возвращает только точное совпадение активного аккаунта. Manage-доступ к курсу проверяется до поиска. В архивный курс добавление запрещено. Disabled/ephemeral-аккаунт добавить нельзя; бан курса не снимается. Повторное членство возвращает 409 без перезаписи роли. Курсная роль независима от системной. Назначить учебную группу можно только студенту, и только из этого курса.

Добавление блокирует курс и аккаунт на время транзакции, чтобы архивация/деактивация не обошла проверку. После успешного добавления старые привязки к учебным группам этого курса очищаются; остальные курсы сохраняются. Устаревшие HTTP-ответы не меняют интерфейс другого курса и не заменяют введённый адрес или черновик.

## Типы вопросов

У каждого из четырёх типов свой черновик ответов. Переключение типа не переносит в него варианты или отметки предыдущего, а возвращение восстанавливает введённые для этого типа данные. Текст вопроса и теги общие.

«Краткий ответ» содержит только допустимые текстовые ответы, без радиокнопок и флажков. Каждая строка сохраняется как правильный ответ. Для одного правильного ответа и «Верно / Неверно» нужна одна отметка, для нескольких правильных хотя бы одна; пустые ответы сохранить нельзя. На время сохранения поля заблокированы.

При редактировании старого краткого ответа прежние варианты с `correct=false` не превращаются в допустимые ответы: форма показывает только отмеченные правильными и предупреждает о необходимости проверить список. Если таких ответов нет, нужно заполнить новый. Запись в банке меняется только при явном сохранении. Ограничение запуска краткого ответа и нескольких правильных в живом занятии сохраняется.

Проверка исправления переключения: реальные сохранение и повторное редактирование всех типов через локальные UI/API, восстановление черновиков, ошибка POST и повтор, старый краткий ответ с неверным вариантом, обе темы на 390/1440 px. Отчёт: `output/playwright/question-type-switch-20261018/`.

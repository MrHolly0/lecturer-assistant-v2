## 4. Что передаётся закрытым каналом

| Данные | Получатель и цель | Ответственный |
|---|---|---|
| Пароль тестового преподавателя | Жюри, если нужен локальный вход | Владелец данных |
| Пароль администратора | Только если жюри проверяет администрирование | Владелец данных |
| Доступ к тестовому MAX-аккаунту | Только утверждённым организаторами способом | Владелец бота |
| `MAX_BOT_TOKEN` | Только по прямому запросу организаторов | Владелец бота |

Не публикуются: серверный `.env`, JWT/slide/internal/webhook secrets, пароль PostgreSQL, cookies, access/refresh tokens, резервные копии рабочей базы и реальные персональные данные.

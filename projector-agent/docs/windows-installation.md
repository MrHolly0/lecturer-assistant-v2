# Установка помощника проектора на Windows

## Состояние пакета

Исходники формируют пользовательский установщик Inno Setup для x64 и ARM64.
Файлы с `unsigned` в имени — сборки для испытаний. Подпись Windows, доверенный каталог
обновлений и физическая проверка HDMI нужны перед публичным распространением.
Cross-publish на macOS подтверждает сборку бинарников, но не работу установщика Windows.

Минимальный фильтр установщика — Windows build 19045. Windows 10 22H2 рассматривается
как отдельная цель проверки совместимости; это не обещание поддержки всех Windows 10.
Фактические требования и сроки поддержки .NET, Windows и WebView2 проверяются перед
релизом. Текущие официальные сведения: [.NET на Windows](https://learn.microsoft.com/dotnet/core/install/windows),
[поддерживаемые ОС .NET 10](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md).
Для ARM64 нужен отдельный установщик; x64-пакет не устанавливается на ARM64 через эмуляцию.

## Что делает установка

- Устанавливает программу только текущему пользователю, без системной службы и открытого
  localhost/LAN-порта. Права администратора не запрашиваются.
- Создаёт стабильную точку запуска, указатель `current.json` и неизменяемый каталог версии.
  Встроенный ZIP проверяется по размеру и SHA-256 до распаковки ограниченным распаковщиком.
- Добавляет программу в меню «Пуск» и в список установленных приложений Windows.
- Предлагает автозапуск отдельным, изначально выключенным флажком. Позже его можно
  включить или отключить через значок помощника в трее. Он указывает на стабильный launcher,
  поэтому обычное обновление не оставляет в автозапуске путь к старой версии.
- Не запускает показ и не меняет конфигурацию экранов при установке. Запуск помощника
  после завершения — отдельный, изначально выключенный флажок; silent install его пропускает.

По умолчанию файлы находятся в `%LOCALAPPDATA%\Programs\LecturerProjector`:

```text
launcher/Projector.Launcher.exe
current.json
versions/<version>-<digest>/app/Projector.Windows.exe
versions/<version>-<digest>/updater/Projector.Updater.exe
installer/bootstrap.json
uninstall/unins000.exe
```

DPAPI-подключение и журнал экранов хранятся отдельно в `%LOCALAPPDATA%\LecturerProjector`.
Установка не содержит пароля сотрудника и не добавляет привязку MAX.

## Повторная установка и обновление

Одинаковый пакет можно установить повторно. Более новый установщик активирует новый
проверенный каталог; более старый не заменяет установленную новую версию или launcher.
Онлайн-обновления используют отдельные подписанные metadata и ZIP, а не запускают
загруженный установщик произвольной командой. Контракт описан в [release.md](release.md).

Установщик не завершает работающий помощник принудительно. Сначала нужно остановить
показ, при необходимости вернуть экраны, затем выйти через значок в трее. Активный показ,
занятый lock и незавершённый журнал обновления блокируют небезопасную замену файлов.
Настройки экранов не восстанавливаются автоматически при установке или удалении.

## WebView2

Помощник проверяет наличие WebView2 Runtime до вывода материалов. Если Runtime отсутствует
или не загружается, в трее появляется понятная подсказка с переходом только на
[официальную страницу Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
Автоматического скачивания и тихой установки дополнительного Runtime нет. Если правила
учреждения запрещают установку, используйте браузерный мастер или обратитесь к администратору.
Evergreen Runtime обслуживается Microsoft; [описание распространения](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution).

## Удаление

Остановите показ, верните сохранённые настройки экранов, затем закройте помощник.
Удаление доступно через меню помощника или «Установленные приложения» Windows.
Удаляются программа, каталоги её обновлений и её запись автозапуска.

Сохранённое подключение отключается отдельным действием «Отключить устройство» до удаления.
Устройство нужно также отозвать на сайте учреждения. Удаление не отправляет команды
отзыва, не удаляет чужие данные и не стирает журнал восстановления экранов.

## Сборка и проверка

На Windows нужны .NET SDK 10, PowerShell 7 и [Inno Setup 6.3+](https://jrsoftware.org/isdl.php):

```powershell
./projector-agent/scripts/build-windows.ps1 -Runtime win-x64 -Version 0.1.0
./projector-agent/scripts/build-windows.ps1 -Runtime win-x64 -Version 0.1.1
./projector-agent/scripts/test-windows-install.ps1 `
  -Installer projector-agent/packages/win-x64/lecturer-projector-win-x64-0.1.0-setup-unsigned.exe `
  -UpgradeInstaller projector-agent/packages/win-x64/lecturer-projector-win-x64-0.1.1-setup-unsigned.exe
```

На ARM64 используются `win-arm64` и `-Platform WINDOWS_ARM64`. Тест установки рассчитан
на отдельный Windows runner: создаёт временную установку, проверяет upgrade/reinstall,
отказ downgrade и удаления при show lock, затем удаляет её. Native UI, автозапуск,
учётные данные и дисплеи он не запускает и не меняет.

До и после upgrade тест также запускает установленный host с `--preflight <report.json>`.
Этот режим выполняется до запуска WinForms, не открывает окно и не получает экраны:
он записывает только новый JSON-отчёт о версии, ОС, архитектуре и наличии WebView2.
Отсутствие WebView2 отражается отдельным статусом и не ломает диагностику.

Для cross-publish без установщика есть `-SkipInstaller`. Сборка возвращает отдельные
`*-update-unsigned.zip`, `*-setup-unsigned.exe` и `package-manifest.json` с вычисленными
размерами/хэшами. `PROJECTOR_TRUST_FILE` может указывать на операторский публичный trust JSON;
private signing key не входит в сборку и не передаётся helper-процессу.

Lecturer Projector — необязательный помощник проектора

Нужны macOS 14 или новее и пакет для вашего процессора: Apple Silicon (arm64)
либо Intel (x64). Сайт и мини-приложение MAX работают без установки.

1. Откройте Lecturer Projector.app с этого диска.
2. Нажмите «Установить в мои Приложения». Компонент установится только для
   вашей учётной записи, без смены конфигурации экранов и без автозапуска.
3. В строке меню появится LA. Откройте «Подключить к учреждению…» и введите
   адрес сайта и одноразовый код из «Настройки проектора». Пароль не нужен.
4. При желании включите «Запускать при входе» в меню LA. macOS может
   запросить разрешение в Системных настройках → Основные → Объекты входа.
5. Настройка экранов меняется только после явной команды. Перед показом
   проверьте код на физическом проекторе. Сайт/MAX остаются пультом.

После перезагрузки повторно скачивать компонент не нужно. Обновления
используют проверяемые пакеты и не заменяют работающую версию во время показа.

Для удаления сначала остановите показ и верните настройку экранов через LA,
затем выберите «Удалить помощник…». Автозапуск отключается, ключ подключения
удаляется, приложение и установленные версии перемещаются в Корзину.
Отзовите устройство также на сайте. Для поддержки: «Сохранить диагностику…».
В диагностике нет токенов, паролей, кода подключения или содержимого занятия.

Корпоративные ограничения и Gatekeeper не обходятся. Если macOS запрещает
установку, используйте браузерный мастер или обратитесь к администратору.

Если рядом лежит DEVELOPMENT.txt, это неподписанная тестовая сборка,
а не готовый публичный релиз. Не отключайте системную защиту ради её запуска.

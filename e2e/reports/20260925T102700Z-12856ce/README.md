## Артефакты

- `summary.json` — машиночитаемые метрики k6.
- `stdout.log` — полный вывод.
- `command.txt` — команда с замаскированным join-code.
- `revision.txt`, `environment.txt` — ревизия, checksum сценария и окружение.
- `controller.log` — фактические моменты смены слайдов, без id сессии.
- `docker-stats.tsv` — один снимок ресурсов.

## Ограничения

- Целевая ревизия не является финальным frozen commit; после заморозки нужен короткий
  повтор на точном hash.
- Смены слайда в этом изолированном тесте делал контроллер через БД по точному
  расписанию. Веб-и MAX-клиенты получают тот же snapshot через SSE, но presenter REST/WS
  путь не входил в этот замер.
